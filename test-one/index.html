Test One — Alchemy Watchdog

Illustrated Windows application testing adventure

This guide was made from the Antigravity report so a young helper can carefully test the Watchdog app on a Windows computer. The drawings are illustrations, not real app screenshots. It works offline. Follow the pictures, do one small step at a time, and mark PASS or NEED HELP.

1) Open this folder

YOUR_WATCHDOG_PROJECT_FOLDER\dist\Alchemy Watchdog

2) Start this file

Start Dashboard.bat

3) Sample files live here

YOUR_WATCHDOG_PROJECT_FOLDER\tests\fixtures

4) Best rule

If something feels scary or confusing, stop and ask a grown-up.

Important: This webpage is only a testing guide. It does not install or run Watchdog. Find the packaged Windows application on your own PC. “YOUR_WATCHDOG_PROJECT_FOLDER” is a placeholder; locate your real project folder in File Explorer.

Grown-up help is needed for these things

  • If Windows shows a security warning like “Windows protected your PC”
  • If you need to change settings files, connect a real CCTV camera, or use real shop data
  • If the app will not open, freezes, or shows a scary error message

Step 1 — Open Watchdog

  1. Open File Explorer.
  2. Go to the folder shown at the top of this guide.
  3. Double-click Start Dashboard.bat.
  4. Wait for a window called Alchemy Watchdog — Ghana Shop.
You should see: a blue [ OFFLINE / LOCAL ] badge and a big dashboard window.
If Windows shows a warning: stop and ask a grown-up to help.
Notes for this step

Step 2 — Meet the 5 Tabs

Click each tab once to make sure it opens.

  • Dashboard Overview
  • Cashier & Till Alerts
  • Incident Review Center
  • Import POS Sales CSV
  • Settings & Tools
You should see: the tab content changes each time you click a new tab.
Notes for this step

Step 3 — Preview a Sample CSV File

  1. Click the Import POS Sales CSV tab.
  2. Click Browse CSV....
  3. Go to this folder:
YOUR_WATCHDOG_PROJECT_FOLDER\tests\fixtures\pos
  1. Choose tolerant_ghana_export.csv.
  2. Click Inspect & Preview.
You should see: preview text showing rows, amounts, or validation details.
Notes for this step

Step 4 — Import and Check Alerts

  1. Still in the CSV tab, click Import to Watchdog.
  2. After import, click the Cashier & Till Alerts tab.
  3. Click Refresh Alerts.

For a stronger test, try these extra sample files one by one:

  • refunds_and_voids.csv
  • discounts_and_no_sales.csv
  • repeated_adjustments.csv
You should see: alerts with types like refund, discount, matched, unmatched, or ambiguous.
Good sign: The app shows alerts as things to review, not accusations.
Notes for this step

Step 5 — Review Incidents

  1. Click the Incident Review Center tab.
  2. Click Refresh Cases.
  3. Look for case rows that show a summary, priority, till, or decision.

You may also try the extra launcher in the app folder:

Review Incidents.bat
You should see: incidents or cases that can be reviewed.
Notes for this step

Step 6 — Try the AI Demo

  1. Close the dashboard if you need to.
  2. In the same app folder, double-click Try CPU AI.bat.
  3. Choose one of the synthetic incident examples.
  4. Read the explanation.
You should see: a local AI explanation that sounds careful and includes the idea that human review is required.
Good sign: it should not call anyone a thief.
Notes for this step

Step 7 — Try the CCTV Viewer

This step is okay with sample video. Do not connect a real store camera without a grown-up.

  1. In the app folder, double-click Start Viewer.bat.
  2. If the viewer opens, try these keys:
  • D = show detection boxes
  • T = show tracking
  • Z = show zones
  • Q = quit viewer
You should see: a viewer window and maybe a sample video with boxes or overlays.
If it does not open: mark NEED HELP and write what happened.
Notes for this step

Step 8 — Finish Your Report

Use the report section below. It will collect your test marks and notes. Then you can print or save it for the grown-up.

Goal: Make it easy to tell the developer what worked and what needs fixing.
