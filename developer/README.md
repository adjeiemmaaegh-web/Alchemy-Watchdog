# For Developer — Alchemy Watchdog stakeholder presentation

This directory contains the 19-slide Alchemy Watchdog visual briefing, including the original PowerPoint slide renders and notes.

## View

Open [the presentation](presentation.html) in a browser, or visit the site's [For Developer section](../for-developer.html). Clone/download the full repository to view offline. Use arrow keys, the thumbnail rail, search, speaker notes, fullscreen and print-to-PDF.

## Fidelity

- All 19 slides are the exact original PNG renders at 1601×900 pixels, not reconstructed marketing mockups.
- To make the large HTML presentation suitable for a version-controlled website, the PNGs are stored in `slides/` instead of embedded as base64 in the HTML.
- Text search and presenter notes are retained in the lightweight `presentation.html` file.
- The visual slide content is not independently editable as HTML text; edit the PowerPoint source for content changes.

## Important boundaries

This is an investor/strategy artifact, not the Watchdog Windows application source or a released product demo. Professional/Enterprise tiers are future ambitions. Camera accuracy, cost savings and commercial readiness have not been proven here. Do not infer authorization to deploy Windows software, operate live surveillance or collect customer data.

No external libraries, embedded trackers, API calls or network dependencies are required by this presentation.
